# ⚡ ASCENSION — Gagne ton temps d'écran par le sport

> **Tu veux scroller sur TikTok ? Fais 20 squats. Tu veux YouTube ? Fais 10 pompes.**

ASCENSION est une app Windows qui transforme tes efforts physiques en temps d'écran mérité. Système RPG complet : XP, niveaux, quêtes, boss hebdomadaires, ligues.

![ASCENSION Banner](https://tomnogues-cmd.github.io/ASCENSION/)

## ⬇️ Télécharger

**[→ Télécharger ASCENSION.exe (gratuit)](https://github.com/Tomnogues-cmd/ASCENSION/releases/latest/download/ASCENSION.exe)**

Portable — aucune installation. Windows 10/11.

## 🎮 Fonctionnalités

- **Système RPG** — XP, niveaux 1→100, rangs, arbre de compétences
- **Quêtes quotidiennes** — 3 quêtes par jour générées aléatoirement
- **Boss hebdomadaire** — objectif collectif, récompense 1000 XP + Coffre Épique
- **Kael** — ta flamme guide qui évolue avec toi (Étincelle → Ascendant)
- **Carte du monde** — 4 zones à débloquer selon ton niveau
- **Ligues** — Bronze → Diamant → Monarque
- **Coffres** — récompenses tous les 5 niveaux
